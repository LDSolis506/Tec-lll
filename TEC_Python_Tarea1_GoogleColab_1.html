Ejercicio 10 — Condicional con validacion de numero entre 10 y 12 — if / elif / else + try/except
NOSI
▼
Celda de texto: ## Ejercicio 10 · luego celda de codigo
→
La sangria (4 espacios o Tab) es obligatoria en Python
Codigo a escribir (respetar la sangria exacta):
try:
    numero = int(input("Ingrese un numero entre el 10 y el 12: "))
    if numero == 10:
        print("el numero ingresado es 10")
    elif numero == 11:
        print("el numero ingresado es 11")
    elif numero == 12:
        print("el numero ingresado es 12")
    else:
        print("Ha ingresado un numero que no esta entre el 10 y el 12")
except ValueError:
    print("Debe ingresar un numero valido")
  1. La sangria son 4 espacios (o un Tab) antes de cada linea dentro de un bloque. En Python la sangria es obligatoria — sin ella el codigo da error.
  2. int(input(...)) convierte la respuesta del usuario de texto a numero entero. Sin el int() el numero llega como texto y las comparaciones no funcionan.
  3. try/except evita que el programa se detenga si el usuario escribe letras en lugar de un numero — en ese caso el bloque except ValueError muestra el mensaje de error.

Ejercicio 12 — Funcion con condicional: si a > b suma, si no resta — a=6, b=9
NOSI
▼
Celda de texto: ## Ejercicio 12 · luego celda de codigo
→
def define la funcion · return devuelve el resultado
Codigo a escribir:
a = 6
b = 9

def operacion(a, b):
    if a > b:
        return a + b
    else:
        return a - b

print(resultado)
  1. Resultado esperado: -3 — porque a (6) no es mayor que b (9), entonces se resta: 6 - 9 = -3.
  2. def operacion(a, b): define la funcion. return devuelve el resultado al lugar donde se llamo la funcion. La ultima linea llama la funcion y guarda el resultado en resultado.

def calculadora():
    num1 = float(input("Ingrese el primer numero (num1): "))
    num2 = float(input("Ingrese el segundo numero (num2): "))

    if num1 < 0:
        print("Division:", num1 / num2)
    elif num1 > 20:
        print("Multiplicacion:", num1 * num2)
    elif num1 > num2:
        print("Suma:", num1 + num2)
    elif num1 < num2:
        print("Resta:", num1 - num2)

calculadora()

    — num1 mayor que num2 (ej. 15 y 8) → debe imprimir Suma
    — num1 menor que num2 (ej. 3 y 10) → debe imprimir Resta
